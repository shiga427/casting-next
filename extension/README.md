# Casting Next 収集ツール（Chrome拡張）

instagram.com のログインセッションで、キャスティング管制室の収集を**ボタン1回**で行う拡張です。
**Claude（LLM）を経由しません。** 取得のみで、DM送信・フォロー・いいね・投稿は一切しません。

収集ロジックは本体と同一（`kit/ig_probe.js` と `kit/prof_compact.js` を `igf/` に同梱）。
この拡張は「instagram.com のタブで収集を回して jsonl を保存する」配線だけを担います。

## なぜ拡張なのか

ダッシュボード（GitHub Pages）は `github.io`、収集対象は `instagram.com` の別オリジンです。
Webページからは別オリジンのログインAPIを叩けません。instagram.com のタブの中でコードを
動かす「乗り物」が必要で、それが拡張です（旧フローで Claude拡張がやっていた役割そのもの・AI抜き）。

## インストール（初回だけ）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」→ この `extension/` フォルダを選ぶ
4. instagram.com に、収集に使うアカウントでログインしておく

## 使い方

1. ダッシュボード（casting-next）で「プールから取得」→「キューを作る」を押す
   （キューが localStorage に書き出されます）
2. ツールバーの拡張アイコンをクリック → ポップアップで「収集を実行」
   - ダッシュボードのタブが開いていればキューを自動取得します
   - 取れない場合は、ハンドルを1行1件でポップアップに貼り付けてもOK
3. instagram.com のタブで収集が回り（1件4〜12秒間隔）、終わると
   `Downloads/casting-next/<run>_compact.jsonl` が保存されます
4. その jsonl をダッシュボードの「取得結果のドロップ」へ入れる → 採点・分析（ここは従来どおり）

進捗はポップアップに出ます。**ポップアップを閉じても収集とダウンロードは完走します**
（収集は instagram.com のタブ側で走るため）。`rate_limited` を検出したら安全に停止します。
時間を置いて同じ手順で再実行すれば、ダッシュボードの取得済み除外で続きから取れます。

## やらないこと

DM送信・フォロー・いいね・投稿・UA偽装は一切しません。取得までがこの拡張の範囲です。

## うまく動かないとき

- ポップアップに「ログインしていません」と出る → instagram.com のタブでログインし、
  そのタブを一度再読込してから再実行
- 「タブへの送信に失敗」→ instagram.com のタブを再読込（拡張の content script を読み直す）
- キューが取れない → ダッシュボードで「キューを作る」を押したか確認、またはハンドルを手貼り
- 取得は成功するのに未ログイン扱いになる（分離ワールドのfetchでCookieが乗らない場合）→
  既知の代替として MAIN ワールド注入に切り替える改修が必要。発生したら報告してください

## ファイル

- `manifest.json` — MV3設定
- `content_ig.js` — instagram.com タブで動く収集ランナー（IGF+__PROF を使う配線）
- `background.js` — 最終JSONLをダウンロード
- `popup.html` / `popup.js` — 操作UI（キュー取得・実行・進捗）
- `igf/ig_probe.js` `igf/prof_compact.js` — 収集ロジック（`../kit/` と同一。更新時は再コピー）
