# 使い方ガイド

## この道具は何をするか

インフルエンサーを**探して・選んで・精査して・声をかける**までの管理をします。
取得(スクレイピング)はしません。取得は**あなたの Claude とあなたの Instagram アカウント**が行い、
この画面はその依頼文を作り、返ってきたファイルを読んで分析します。

- データは**このブラウザの中(IndexedDB)**にだけ保存されます。サーバには何も送りません
- 共有・引き継ぎは「データ入出力」からの JSON 書き出しで行います
- DM送信・フォロー・いいね・投稿は**一切しません**

## 1周の流れ(5ステップ)

1. **収集**画面で「キューを作る」→「依頼文を作ってコピー」
2. コピーした依頼文を、あなたの Claude に貼り付ける
3. Claude が Instagram のタブでプローブを注入し、fetch だけで取得して `run<N>_compact.jsonl` を返す
4. そのファイルを**収集**画面にドラッグ&ドロップ
5. その場で分析され、**分析結果**画面が出る。機械合格者は**候補ボード**に自動で入る

## 画面の見方

| 画面 | 何をするところ |
|---|---|
| 概要 | KPIと自動診断アラート。まずここを見て「今日やること」を決める |
| 候補ボード | 得点率順の候補一覧。行をクリックすると詳細(採点内訳・証言力rubric・適合コメント) |
| パイプライン | 候補→精査済→DM送付→…のカンバン。DM送付から5営業日で催促アラート |
| 分析結果 | run ごとの取得成績・落ち理由・語りの向き・隔離リスト |
| 精査・定性評価 | 3ファイルをドロップ → 証拠の下書きが出る。結論はあなたが書く |
| 探索カバレッジ | 計画した探索の実行状況。**未実行を隠さない**ための表 |
| 敗者復活 | 機械フィルタの落選者。境界例は手で戻せる |
| 収集 | キュー生成・依頼文・結果ドロップ・取得履歴 |
| データ入出力 | 管制室 v1.4 のJSON読み込み / v4 JSON の書き出し・読み込み / 保存データの消去 |
| 設定・基準 | 採点パラメータ。**変更には理由とバージョンが必須** |
| 運用ログ | 指示書にない判断の事前承認記録 |

## 用語

- **SBIS-1**:機械で付く点(精査の優先順位付け。合否ではありません)
- **得点率**:得点 ÷ その候補の満点。救済採点(75点満点)の候補と同じ土俵で比べるための値
- **救済採点(SBIS-1s)**:いいね非表示でERが測れない候補。②ERを配点から外し75点満点で採点します
- **紹介者**:直近8投稿のタイアップ比率が50%超。T1=0点・原則見送り
- **語りの向き(stance)**:当事者型(証言者向き)/権威型(語りの終着点が自社導線)/カタログ型/判定保留
- **純度ハードゲート**:フォロー3,000超 または FF比2.0未満は足切り(相互フォロー網の疑い)

## 困ったとき

| 症状 | 対応 |
|---|---|
| Chrome拡張が繋がらない | 収集画面の「準備チェック」の3点(拡張・サイト権限・IGログイン)を順に確認 |
| rate_limited が出た | その run は打ち切り、翌日以降に残りを再キュー(取得済みは自動で除外されます) |
| 欠測が出た | プローブを再注入して再取得(依頼文に手順が入っています) |
| JSONL がドロップで弾かれる | エラー内容をコピーして Claude に渡してください(何行目の何が足りないかを表示します) |
| 定性判定が低く出る | キャプション上限が140字未満の可能性。収集画面で `__CAP` を確認して再取得 |
| 自動保存が使えないと出る | プライベートモードの可能性。作業前後に必ず JSON 書き出しを |

## Instagram を使ううえでの注意

- ご自身のアカウントで公開情報を閲覧する範囲の取得です
- 自動化には凍結等のリスクがゼロではありません。**リスクの引き受け主体は利用者**です
- 依頼文はペース制限(間隔・件数上限・429での中断)を守る内容になっています
- DM送信・フォロー・いいね・投稿など能動的な操作は一切しません
