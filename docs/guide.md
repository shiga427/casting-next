# 使い方ガイド

## この道具は何をするか

インフルエンサーを**探して・選んで・精査して・声をかける**までの管理をします。
取得は **Casting Next 拡張**（このリポジトリの `extension/`）が、あなたの Chrome とログイン中の
Instagram アカウントで行います。この画面は**拡張に渡す条件を決め、返ってきた結果を読んで分析します**。

- データは**このブラウザの中(IndexedDB)**にだけ保存されます。サーバには何も送りません
- 共有・引き継ぎは「データ入出力」からの JSON 書き出しで行います
- 書き込み操作は**候補ボードでチェックした候補へのDM送付だけ**です。フォロー・いいね・投稿は**一切しません**

> 拡張の入れ方: `chrome://extensions` →「デベロッパーモード」をオン →
> 「パッケージ化されていない拡張機能を読み込む」→ リポジトリの `extension/` フォルダを選ぶ。

## 1周の流れ(5ステップ)

1. **収集**画面で、拡張に渡す条件を決める
   - **初めてなら「① 発掘から始める」**:探索タグを選ぶだけ（**手持ちのリストは不要**）。
     選んだ時点で拡張に渡ります（「最終送信 HH:MM」で確認できます）
   - **2周目以降は「② プールから取得」**:1周目で集まったハンドルがプールに貯まっているので、
     「キューを作る」を押す。取得済みは自動で除外されます
2. instagram.com のタブを開いた状態で、**拡張ポップアップの「①発掘して収集」／「②プールから取得」**を押す
3. 拡張が instagram.com のタブで収集します（ポップアップを閉じても最後まで走ります）。
   間隔・件数上限・429での中断は拡張が守ります
4. 終わると `run<N>_compact.jsonl` が Downloads に保存され、**この画面に自動で取り込まれます**
   （ダッシュボードのタブを開いたままにしてください。閉じていた場合は保存されたファイルを手でドロップ）
5. その場で分析され、**分析結果**画面が出る。機械合格者は**候補ボード**に自動で入る

取り込んだときに、集まったハンドルは**プール**へ、取得したハンドルは**取得済み台帳**へ、
タグごとの件数は**探索カバレッジ表**へ自動で記録されます。次回の重複取得はこれで防がれます。

## 精査(定性評価)の流れ

1. 対象は**スコア60点以上**の候補（得点率の高い順）。1回あたりの人数上限はありません
2. 60点以上が10名に満たないときは、**拡張の「③精査データ」が自動で発掘して母数を補充**します
3. 拡張ポップアップの「③精査データ」→「ダッシュボードの精査待ちを取り込む」→「精査データを集める」
4. captions / comments / profile の3ファイルが**精査画面に自動で入り**、証拠の下書きが出ます
5. 結論（役割・魅力・懸念など6欄）は**あなたが書きます**。未記入のままでは「精査完了」にできません

## 画面の見方

| 画面 | 何をするところ |
|---|---|
| 概要 | KPIと自動診断アラート。まずここを見て「今日やること」を決める |
| 候補ボード | 列見出しをクリックで並べ替え。行をクリックすると詳細(採点内訳・証言力rubric・適合コメント・精査結果) |
| パイプライン | 候補→精査済→DM送付→…のカンバン。DM送付から5営業日で催促アラート |
| 分析結果 | run ごとの取得成績・落ち理由・語りの向き・隔離リスト |
| 精査・定性評価 | 拡張が集めた3ファイルから証拠の下書きが出る。結論はあなたが書く |
| 探索カバレッジ | 計画した探索の実行状況。**未実行を隠さない**ための表 |
| 敗者復活 | 機械フィルタの落選者。境界例は手で戻せる |
| 収集 | 発掘タグ・キュー生成（＝拡張に渡す条件）・結果の取り込み・取得履歴 |
| データ入出力 | 管制室 v1.4 のJSON読み込み / v4 JSON の書き出し・読み込み / 保存データの消去 |
| 設定・基準 | 採点パラメータ。**変更には理由とバージョンが必須** |
| 運用ログ | 指示書にない判断の事前承認記録 |

## 用語

- **SBIS-1**:機械で付く点(精査の優先順位付け。合否ではありません)
- **得点率**:得点 ÷ その候補の満点。救済採点(75点満点)の候補と同じ土俵で比べるための値
- **救済採点(SBIS-1s)**:いいね非表示でERが測れない候補。②ERを配点から外し75点満点で採点します
- **紹介者**:直近8投稿のタイアップ比率が50%超。T1=0点・原則見送り
- **語りの向き(stance)**:当事者型(証言者向き)/権威型(語りの終着点が自社導線)/カタログ型/判定保留
- **純度ハードゲート**:フォロー3,000超 または FF比2.0未満は足切り(相互フォロー網の疑い)

## 困ったとき

| 症状 | 対応 |
|---|---|
| 拡張のボタンが押せない / 結果が入らない | ①ダッシュボード(この画面)のタブを**開いたまま**にする ②instagram.com のタブを閉じない ③`chrome://extensions` で拡張を「更新」してから再実行 |
| 拡張が繋がらない | 収集画面の「準備チェック」の3点(拡張の読み込み・サイト権限・IGログイン)を順に確認 |
| rate_limited が出た | その run は打ち切り、時間をおいて再実行(取得済みは自動で除外されるので続きから走ります) |
| 欠測が出た | **拡張で同じ対象をもう一度収集**すると users_info 経路で復旧します(run#6 で 20/20 復旧) |
| JSONL が取り込みで弾かれる | 「このエラーをコピー」で内容を控えてください(何行目の何が足りないかを表示します) |
| 定性判定が低く出る | キャプションが短い取得データの可能性。**旧取得データで起きる症状**です(現行の拡張は全文を取ります)。拡張で取り直してください |
| 自動保存が使えないと出る | プライベートモードの可能性。作業前後に必ず JSON 書き出しを |

## Instagram を使ううえでの注意

- ご自身のアカウントで公開情報を閲覧する範囲の取得です
- 自動化には凍結等のリスクがゼロではありません。**リスクの引き受け主体は利用者**です
- **拡張がペース制限(間隔・件数上限・429での中断)を守ります**
- 能動的な操作は「人がチェックした候補へのDM送付」だけです。フォロー・いいね・投稿はしません
